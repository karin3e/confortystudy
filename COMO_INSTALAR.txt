COMFORTSTUDY — PACOTE FIREBASE + GITHUB PAGES

IMPORTANTE: o pacote de código está preparado, mas não pode autenticar contas reais até você criar/configurar seu projeto Firebase. Não publique como pronto para o público antes dos testes do arquivo CONFIGURAR_FIREBASE.md.

ARQUIVOS
- index.html: login com Firebase Authentication
- cadastro.html: criação de conta real
- recuperar-senha.html: envio de link de redefinição por e-mail
- index_2.html + script.js + style_dashboard.css: painel e funções existentes
- firebase-config.js / firebase-init.js / auth.js / cloud-sync.js: integração Firebase
- firestore.rules: regras de acesso por usuário
- manifest.json / service-worker.js / icons/: instalação PWA

PASSOS
1. Crie um projeto em https://console.firebase.google.com/.
2. Ative Authentication > E-mail/senha. Ative Google se quiser login Google.
3. Crie um banco Cloud Firestore.
4. Copie a configuração do aplicativo Web para firebase-config.js, substituindo todos os valores COLOQUE_... .
5. Publique as regras de firestore.rules em Firestore Database > Rules.
6. No Authentication > Settings > Authorized domains, adicione SEU-USUARIO.github.io (sem https e sem caminho).
7. Envie todos os arquivos e a pasta icons para o repositório GitHub Pages.
8. Abra o endereço HTTPS e teste criação de conta, login, recuperação de senha, dados sincronizados em dois dispositivos e isolamento entre duas contas.

SEGURANÇA E LIMITAÇÕES
- Não há senha administrativa nem service-account neste pacote. Nunca coloque credenciais administrativas no GitHub.
- As senhas são geridas pelo Firebase Authentication; o projeto não salva senhas no localStorage.
- Dados antigos do protótipo só são importados quando o e-mail local anterior coincide com o e-mail autenticado. Faça backup antes de atualizar.
- Notificações com o app totalmente fechado exigem Web Push e um serviço de envio no servidor; ainda não estão incluídas.
- Cobrança Premium, domínio próprio, política de privacidade/termos e testes reais de produção ainda precisam ser configurados antes de divulgar publicamente.
