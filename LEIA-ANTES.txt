COMFORTSTUDY — ARQUIVOS PARA SUBSTITUIR

Este pacote contém apenas os 3 arquivos alterados, já no caminho da raiz do repositório:
- script.js
- style_dashboard.css
- service-worker.js

COMO APLICAR
1. Faça uma cópia de segurança do repositório local.
2. Extraia estes 3 arquivos diretamente na pasta raiz do repositório confortystudy.
3. Confirme que o Windows substituiu os arquivos existentes.
4. No terminal, dentro da pasta do repositório, execute:
   git status
   git add script.js style_dashboard.css service-worker.js
   git commit -m "Aprimora icones e fluxo de upload das materias"
   git push origin main

Observação: este pacote não contém .git e não publica nada sozinho. O git push é feito no seu computador, usando sua configuração já existente. Teste o upload no site depois da publicação.
