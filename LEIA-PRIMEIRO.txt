COMFORTSTUDY — PACOTE DE RECUPERAÇÃO COMPLETO

Este pacote contém os arquivos do site organizados para publicar pela RAIZ do repositório GitHub Pages. index.html é a página inicial/login; index_2.html é o painel.

ANTES DE COPIAR
1. No VS Code, faça uma cópia de segurança da pasta atual do projeto.
2. Extraia este ZIP em uma pasta separada.
3. Copie os ARQUIVOS E A PASTA icons que estão dentro do ZIP para a pasta raiz do repositório local confortystudy (a mesma pasta em que fica a pasta .git). Não copie uma pasta externa adicional.
4. Se o Windows perguntar se deseja substituir arquivos, só confirme depois de ter a cópia de segurança.
5. No terminal do VS Code, confira que está na pasta raiz do repositório. Execute: git status
6. Se o status mostrar os arquivos esperados, execute: git add .
7. Depois: git commit -m "Restaura arquivos do ComfortStudy"
8. Depois: git push origin main
9. No GitHub, abra Settings > Pages e escolha Deploy from a branch, branch main, pasta /(root). Aguarde o deploy terminar.

FIREBASE
O firebase-config.js deste pacote já contém a configuração web informada para o projeto confortstudy-9ab7d. No Firebase Console, confirme que Authentication > E-mail/senha está ativado, que o domínio karin3e.github.io está autorizado e que o Firestore foi criado e recebeu as regras do arquivo firestore.rules.

IMPORTANTE
- Não apague a pasta antiga antes de confirmar que o site abre.
- Se git status indicar conflito, rebase, ou arquivos inesperados, pare e peça ajuda antes de executar mais comandos.
- GitHub Pages publica apenas arquivos estáticos. O login real depende de Firebase Auth/Firestore configurados corretamente. Notificações com o site fechado e cobrança Premium real exigem configuração adicional.
